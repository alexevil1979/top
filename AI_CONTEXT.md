## Следующий шаг
1. На VPS:
   - Обновить код: `cd /ssd/www/top && git pull origin main`
   - Проверить подключение к БД через `https://top.1tlt.ru/admin/db_check.php`
   - Убедиться, что админ-панель (`/admin/index.php`) открывается без ошибок 500
   - Запустить проверку системы: `https://top.1tlt.ru/admin/system_check.php`
2. В админке:
   - Задать реальный YouTube API ключ в разделе «Настройки» (использовать кнопку проверки)
   - Проверить все компоненты через «Проверку системы»
   - Создать рабочие подборки и расписания
3. Протестировать ночной запуск cron и убедиться, что:
   - В таблицу `shorts` попадают новые записи
   - В `storage/frames` сохраняются кадры
   - В `execution_logs` пишутся корректные логи
